# 直接表示する4入口と合格クエスト販促デザイン

更新日：2026-09-16

## 共通ナビゲーション

- 学ぶ「合格クエスト」：`/quest/`
- 旅する「車旅」：従来の車旅ランディングページを表示
- つくる「キャンパーDIY」：`/camping.html` を直接表示
- 整える「ハイエース整備」：`/maintenance.html` を直接表示

トップページの車旅・DIY・整備カードと、各ページ上部の共通ナビゲーションも同じ遷移先に統一しています。

## 合格クエスト

合格クエストのトップ、理科、社会、国語、英語の案内ページに、旧アプリ紹介ページの販促表現を取り入れました。

- 教科別のアクセントカラー
- 太い枠線とオフセットシャドウ
- アプリ紹介画像を前面に出したヒーロー
- 教科を選びやすいカード
- ストア・教科選択への明確なCTA
- ダウンロード無料・アプリ内課金あり等の確認事項

学習内容、料金、対応端末などは、各紹介ページとストアの最新表示を優先します。

## 保持した機能

キャンピングカー3D、ハイエース3D、整備記録の保存・再読み込み・JSON書き出し、ドライブルート地図、既存の規約本文は保持しています。
