# TrailFusion ブランドサイト（2026-10-25 全面改修）

ユーザー指示「トップのコンセプトがわかりづらい。ハイエース整備やキャンピングカーの作り方は個人の趣味なので最適な配置に。
合格クエストのような美しく明るいデザインに全部作り変える。アプリが基本で、ど真ん中は合格クエスト。もちのへや・車旅コンシェルジュ・
Reel Make などを紹介し、TrailFusion というブランドとそのアプリに信頼感を持てるように」。言語は「日本語＋英語だけ」（ユーザー選択）。

## 構成

| URL | 役割 |
|---|---|
| `/` `/en/` | ブランドのトップ。ヒーロー（合格！クエストを「いちばんの自信作」として大きく）→ 数字（App Store の実データ）→ 合格！クエスト → もちのへや・車旅コンシェルジュ・Reel Make・VoiceLink → ほかのアプリ → 信頼のための約束 → つくり手とガレージ → FAQ → ダウンロード |
| `/apps.html` `/en/apps.html` | 全アプリのカタログ（分類で絞り込み・状態・ストア・規約/プライバシー/サポート）。以前の単科アプリ（理科・国語）は別枠 |
| `/about/` | つくり手（創業者の話・原則・数字）。旧ページの本文を新デザインで整理 |
| `/garage/` | **趣味の置き場**。車旅の記録・絶景ロード図鑑・キャンピングカーDIY・ハイエース整備。アプリとは分け、トップ下部とフッターから入る |
| `/quest/` | 合格！クエストの専用サイト（`docs/quest/README.md`）。今回は変更なし |
| その他の330ページ | 本文はそのまま、ヘッダー・フッター・配色だけ新ブランドに差し替え。各ページの言語切り替え（`div.tf-extra`）は新ヘッダーへ移して残す |
| `/zh-hans/` ほか13言語 | 廃止。英語版への転送（noindex）。サイトマップからも外した |

## 作り方

```sh
python3 scripts/brand/prepare-assets.py --jyuken /Users/user/jyuken_sience --mochi ~/swift/MochiPet --garage <codex session/file>
python3 scripts/brand/build.py        # 新ページ生成＋既存ページのヘッダー差し替え＋転送＋sitemap/llms.txt（何度実行しても同じ結果）
python3 scripts/brand/make-og.py      # OG画像（Webフォントを読み込んだヒーロー）
python3 scripts/brand/check-static.py # 公開処理と同じ静的チェック
python3 scripts/brand/validate.py     # Chrome/WebKit・320/390/768/1440px・操作・JS無効
```

- 部品: `scripts/brand/brandsite.py`（アプリのデータ・ヘッダー・フッター・ページの雛形）、`home.py`（トップ）、`pages.py`（一覧・つくり手・ガレージ）。
  モジュール名を `site` にすると Python 標準の `site` と衝突する。
- スタイル: `assets/css/brand.css`（新ページ用＋既存ページの再配色）、`assets/js/brand.js`（メニュー・絞り込み・ストアのクリック計測）。
- 公開処理（`.github/workflows/deploy.yml`）はコミット済みのHTMLを検査するだけで書き換えない。旧来のデプロイ時CSS注入と15言語の再生成は削除した。

## 数字と表現の根拠

- アプリの名前・版・更新日・評価: `docs/brand/store-snapshot.json`（iTunes lookup、App Store 日本、2026-10-25 取得）。公開中は同じ開発者アカウントの12本。
- 合格！クエストの問題数・図鑑ページ: `docs/quest/course-stats.json`。
- もちのへやは審査中のためストアリンクを出さず「審査中・まもなく公開」と表示。数にも含めない。
- 47都道府県・約5万km・家族の中学受験・親子の北海道旅は、旧「つくり手」ページの本人の文章から。
- 利用者の声・合格率・順位などは載せていない。アプリはすべて無料ダウンロード（一部アプリ内課金）。

## 画像

- 背景: Codex の画像生成（文字・人物なし）。`docs/brand/assets.json` に出典とSHA。ガレージの絵は実在の車種に似ない箱型バンで描き直した。
- アプリのアイコン・画面: App Store の公式素材、合格！クエストはアプリのアイコンと実画面、もちのへやはアプリのプロジェクトの素材。

## アプリの詳細ページ（2026-10-25 第2弾）

ユーザー指示「全てのセクションの裏側に、そのアプリやセクションを示す背景画像を」「各アプリの詳細ページも同じ高品質に」。

- 13アプリの詳細ページを新デザインで作り直した（`scripts/brand/detail.py`＋本文 `apps_content.py`）。構成は
  ヒーロー（アイコン・評価・実画面3枚）→ できること → 画面ギャラリー（App Store の画面を最大6枚、英語ページは米国ストアの英語画面）
  → 使い方・こんな方に → 料金・注意・規約リンク → ほかのアプリ → ダウンロード。英語版は11本（車旅コンシェルジュは日本のみ配信、理科・国語の単科は日本語のみ）。
- もちのへやは `/mochi.html` を新設（審査中・ストアリンクなし）。FPクエストは `/fp-quest.html` を新設。
- 本文は各アプリの App Store の説明文（日本・米国、2026-10-25取得）から。料金はストアに書かれている範囲だけ。
- **すべてのセクションに背景画像**: トップ・一覧・つくり手・ガレージ・詳細ページの各 `<section>` は `picture.bg` を持つ（`validate.py` が確認）。
  文字の読みやすさは `.veil`（白い半透明の層）で確保。背景はアプリごとに選ぶ（Reel Make＝写真とフィルムの机、VoiceLink＝世界地図、
  BuddyTalk＝カフェ、English Quest＝図書室、FP＝貯金箱、Word Blaster＝宇宙、ウッドゴーレム＝森、タイマー＝砂時計、理科＝顕微鏡、国語＝筆と和紙、
  もちのへや＝桃色のおへや、車旅＝海沿いの道と車中泊の車内、一覧＝模型の棚、FAQ＝丘のポスト、信頼＝紙飛行機）。合格！クエストの節は /quest/ の王国の絵を使う。
- 背景の生成は Codex。追加16＋1枚の出典とSHAは `docs/brand/assets.json`。
