# 海外向けアプリ紹介と35言語表示（2026-11-15）

## 最新のユーザー方針

- 海外の主役はReel MakeとVoiceLink AI Translator。
- Japanese Quest・English Questは、**既に統合済みのGokaku Quest内の日本語・英語教材**として紹介する。今から統合・移行する作業ではない。
- BuddyTalkも海外向けの英会話アプリとして紹介する。主力は4アプリ、入口は5用途。2教材を別カードにしてもQuestを二重に数えない。
- 日本の受験向けの社会・理科などの画像、説明、総教材数を海外主導線から外す。
- 公開ストアで確認した対応UI言語のunion 35言語をWeb表示に用意する。各アプリが35言語すべてで同じ機能を提供するという意味ではない。
- 日本語本文、国内のQuest専用サイト、DIY・整備の作業は維持する。

この方針が、過去の「日本語＋英語だけ」「他13言語を退役」「英語版でも国内教材を主役にする」方針を置き換える。

- 各localeのトップ：作成・通訳の2アプリ → 語学3入口 → 信頼・つくり手・FAQ。
- アプリ一覧：主な5入口にWord Blaster／Wood Golem／Hacking Timerを続ける。8カード・7アプリ。語学フィルターは4カード・3アプリ。
- /en/japanese-quest.html：Gokaku Quest内の日本語教材。App Store ID 6775411516、Google Play com.gokakushakaiquest.appへ接続する。
- /en/eigo-quest.html：同じGokaku Quest内の英語教材。国内トップ・一覧のEnglish Questも統合内教材として紹介し、独立版ID 6782028599への集客は行わない。旧 /eigo-quest.html は /quest/courses/english/ へ転送し既存URLを保全。
- /en/buddytalk.html：ID 6744263274。現ストア2.0.0の説明へ合わせた。
- 共通ナビ・関連カードも上記へ接続。構造化データはGokaku Questを1 MobileApplication、その中に2 LearningResourceとして記述する。

- Reel Makeの既設Google Play URL com.reelapp.makerはUS/JPともHTTP 404のため、日本語版を含め全言語でApp Storeのみ。正しい公開URLが確認できたら復旧する。
- App Storeは国固定のない https://apps.apple.com/app/id... を使用。Google Playも言語・国を固定しない。価格・提供可否はストア/購入画面の地域別最新表示を参照する。

## 言語構成

公開一次情報のUI言語を合わせた対象：
ar, ca, hr, cs, da, nl, en, fi, fr, de, el, he, hi, hu, id, it, ja, ko, ms, nb, pl, pt, ro, ru, zh-Hans, sk, es, sv, th, zh-Hant, tr, uk, vi, ne, fil。

- 日本語は既存国内版、英語は原文。33言語を新規翻訳し、海外34言語×10ページ＝340の静的HTMLを生成する。
- 対象テンプレート：トップ、一覧、Reel Make、VoiceLink、日本語教材、英語教材、BuddyTalk、Word Blaster、Wood Golem、Hacking Timer。
- 本文・ナビ・alt・ARIA・meta・JSON-LD・動的カウンターの409キー。語順が変わる見出し・キャッチは42キーの文全体訳。外国語へ断片順序を強制しない。
- /zh-hans/と/zh-hant/を分ける。Portugueseは既存URL /pt-br/を維持しHTML言語はpt。fr-CA/pt-PTなどは利用可能な言語版へ解決する。
- Filipinoは/fil/とHTML lang=fil。検索用hreflangはISO 639-1のtlへマップ。navigatorのtlもfilへ正規化。
- 各URLはself canonical、相互hreflang、通常の言語リンクを持つ。JavaScript無効でも翻訳本文とリンクを使える。
- Arabic/Hebrewはdir=rtl。スクリーンショットは実画面を使いaltと説明を翻訳する。英語教材の日本語解説付き図鑑は、その旨を説明する。

UI言語・翻訳言語・音声数・学習言語・説明言語は別の概念。Reelの「60 voices」を「60言語」に読み替えない。VoiceLinkの翻訳20言語とWeb表示35言語を混同しない。Questの教材・OS・バージョンごとの説明言語の違いを明記する。

## 自動表示

global-locale.jsは静的URLの選択だけを行う。翻訳API、外部IP検索、位置情報、タイムゾーンの国推定は使わない。

優先順位は、明示locale URL／明示選択 → 保存された言語（無言語入口だけ）→ navigator.languagesの希望言語 → 英語。

- 自動判定は/と/apps.htmlだけ。/fr/等の明示URLは上書きしない。
- 日本語入口2ページの本文は変更せず、headの言語情報とheaderのpickerだけを追加。日本語8詳細はheadに相互hreflangのみ追加し、詳細ページのx-defaultは英語へ合わせる。
- UTM等のqueryとhashを維持。手動日本語選択はstorage不可でも?lang=jaで再読み込み後も維持。
- 35言語pickerから変更でき、「自動」で保存指定を解除できる。
- これは閲覧者の希望言語への最適化であり、実際の滞在国を検出する仕組みではない。

## 生成と検証

~~~sh
python3 scripts/brand/build.py --global-only
python3 scripts/brand/check-static.py
node scripts/add-visitor-counters.mjs --check
node --test tests/visitor-counter.test.mjs tests/global-locale.test.mjs
python3 scripts/brand/validate.py
python3 scripts/brand/validate-global.py
~~~

global_content.pyが原文、global_i18n.pyが全言語生成、locales/en.jsonとheadings.en.jsonが原文キー、同名locale JSONが訳文。欠損キーがあれば生成を停止し、英語fallbackのまま公開しない。--global-only --locales en,arは部分プレビュー専用で、全340ページが揃わない成果は公開ゲートで失敗する。

check-static.py → check-global.pyで全ページ・実リンク・canonical/hreflang・翻訳キー/placeholder/英語残り・正しい統合Quest ID・利用不能Reel Androidリンク非表示を検査。ルーターとPVの17テスト。件数表示は単複の誤りを避け「アプリ：件数」の形。

Chrome/WebKitで主要国内ページとRTL/CJK/長文の各国語ページを検証。通常リンク、JS無効、保存不可、メニュー、UTM/hash、重複除外した件数も確認。日本語トップ・一覧はEnglish Questの紹介・ストア先・重複アプリ件数だけを修正。日本語Reel Makeの紹介も検証済みApp Storeだけを表示する。その他の国内Quest本文・DIY・整備HTMLは変更しない。既存ブラウザゲート742項目、国際版292項目も成功した。
