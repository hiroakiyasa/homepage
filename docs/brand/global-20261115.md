# 海外向けアプリの訴求整理（2026-11-15）

## 最新のユーザー方針

- 海外の主役は Reel Make と VoiceLink AI Translator。
- Japanese Quest・English Quest・BuddyTalkを、海外向けの語学アプリとして明確に紹介する。
- 日本の受験向けの社会・理科などの画像、説明、総教材数を海外向けの主導線から外す。
- 日本語版、国内の合格！クエスト専用サイト、DIY・整備の作業は維持する。

## 構成

- /en/：作成・通訳の2アプリ → 語学3入口 → 信頼・つくり手・FAQ。
- /en/apps.html：主要5入口を先頭に、Word Blaster／Wood Golem／Hacking Timerを続ける。
- /en/japanese-quest.html：新しい英語の日本語学習入口。Japanese QuestはGokaku Quest内の日本語教材と明記。既存統合版ID 6775411516とAndroid com.gokakushakaiquest.appに接続する。独立した架空アプリIDは作らない。統合版の英語教材も案内する。
- /en/eigo-quest.html：独立English Quest（ID 6782028599）の既存LP。
- /en/buddytalk.html：既存ID 6744263274。英語本文のみ現ストア2.0.0の説明と一致させた。
- 各英語LPの共通ナビ・フッター・関連カードを主要5入口へ変更。
- /en/fp-quest.html：日本語正規ページへ転送。noindex、サイトマップ対象外。
- 英語OG画像はReel MakeとVoiceLinkの実画面を使用。日本語OGは変更しない。

## 再生成

```sh
python3 scripts/brand/build.py --english-only
python3 scripts/brand/make-global-og.py
python3 scripts/brand/check-static.py
node scripts/add-visitor-counters.mjs --check
node --test tests/visitor-counter.test.mjs
python3 scripts/brand/validate.py
```

global_content.pyが英語専用の構成を持つ。--english-onlyは英語LPと該当サイトマップ項目だけを更新し、日本語や趣味のHTMLを再生成しない。通常の全体生成も同じ英語構成を呼ぶ。

## 検証
