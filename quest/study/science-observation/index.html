例題 1 / 生物の観察と分類

道具を使う目的

顕微鏡でプレパラートをのせる場所はどれですか。

  1. 鏡筒
  2. ステージ
  3. 接眼レンズ
  4. 反射鏡
答えと解説を読む

正解：2．ステージ

ヒント
観察した事実と、生き物の体のつくりを結びつけて考えよう。

解説
正解の「ステージ」が正しい理由は、ステージはプレパラートを平らに置いて固定する台です。標本を動かさずに観察するための場所なので、最初にここへ置きます。 この問題の「顕微鏡でプレパラートをのせる場所はどれですか」という条件が、その判断の根拠です。次に似た問題では、見つけた場所、形、数、時刻などを具体的に記録し、体のつくりやくらしと結びつけて考えましょう。

例題 2 / 生物の観察と分類

場所を記録する理由

生き物を見つけた場所も記録する一番の理由はどれですか。

  1. 体の色が変化した原因を決められる
  2. 名前をその場で必ず特定できる
  3. くらし方を考える手がかりになる
  4. 観察した生き物の年齢を計算できる
答えと解説を読む

正解：3．くらし方を考える手がかりになる

ヒント
観察した事実と、生き物の体のつくりを結びつけて考えよう。

解説
正解の「くらし方を考える手がかりになる」が正しい理由は、見つけた場所には光、水分、温度などの違いがあります。場所を記録すると、その生き物がどんな環境を好むかを後で考えられます。 この問題の「生き物を見つけた場所も記録する一番の理由はどれですか」という条件が、その判断の根拠です。次に似た問題では、見つけた場所、形、数、時刻などを具体的に記録し、体のつくりやくらしと結びつけて考えましょう。

例題 3 / 生物の観察と分類

比べる条件をそろえる

葉の表と裏のちがいを調べるとき、同じ葉で比べるよさはどれですか。

  1. 葉についた虫の影響をすべて除ける
  2. 葉ごとのちがいを除いて比べられる
  3. 表と裏で葉の色を同じにそろえられる
  4. 葉を切らずに内側のつくりまで見える
答えと解説を読む

正解：2．葉ごとのちがいを除いて比べられる

ヒント
観察した事実と、生き物の体のつくりを結びつけて考えよう。

解説
正解の「葉ごとのちがいを除いて比べられる」が正しい理由は、同じ葉の表と裏を比べれば、葉の種類・育ち方・日当たりなど、葉ごとのちがいをできるだけ除けるからです。表と裏そのものの違いを調べやすくなります。 この問題の「葉の表と裏のちがいを調べるとき、同じ葉で比べるよさはどれですか」という条件が、その判断の根拠です。次に似た問題では、見つけた場所、形、数、時刻などを具体的に記録し、体のつくりやくらしと結びつけて考えましょう。

解いたあとは、考え方を整理。

1．道具は「何をするためか」とセットで覚える

顕微鏡の部品名を覚えるときは、観察する物を置く場所、目でのぞく場所というように、使う場面と結びつけます。例題では、プレパラートをのせる場所を確かめます。

図鑑で全体のつくりを見たあと、名前を隠して役割を説明してみましょう。正解の番号を覚えるだけで終わらず、選んだ理由まで言えるかを確認します。

2．観察の記録には、見つけた環境も残す

形や色だけでなく、どこで見つけたかを記録すると、光や水分などの環境と、生き物のくらし方を結びつけて考えられます。見た事実と、そこから考えたことを分けて書くと、あとから比べやすくなります。

3．比べたいもの以外の違いに気づく

葉の表と裏を比べるなら、違う種類の葉を1枚ずつ使うと、表裏の違いなのか葉そのものの違いなのかが分かりにくくなります。同じ葉で比べる意味を、例題の解説で確認しましょう。

学習の順番は「比べたいことを決める→そろえる条件を考える→結果を記録する」。文部科学省の理科資料でも、比較や条件を整理しながら観察・実験を進める考え方が扱われています。
