例題 1 / 数値の内部表現と計算の限界

1のある桁の重みを足す

2進数10110を10進数で表したものはどれか。

  1. 30
  2. 20
  3. 26
  4. 22
答えと解説を読む

正解：4．22

ヒント
1がある桁の重みを足し合わせる。

解説
各桁の重みは右から1、2、4、8、16である。10110は1の桁の重みを足し、16＋4＋2＝22となる。0の桁の重みを含めると30となり、正しく計算できない。

例題 2 / 数値の内部表現と計算の限界

種類の数と最大値を区別する

5ビットの符号なし整数で表せる最大値を、10進数で示したものはどれか。

  1. 63
  2. 31
  3. 16
  4. 32
答えと解説を読む

正解：2．31

ヒント
0も表現する値の一つに含まれる。

解説
最大のビット列11111は16＋8＋4＋2＋1＝31を表す。32は0を含む表現可能な値の個数であり、最大値ではない。63を表すには6ビット必要で、16は最大値より小さい。

例題 3 / 情報量と文字・記号の符号化

必要な種類数を入れられる桁数を探す

21種類のスタンプに、それぞれ異なる固定長の2進符号を付ける。1種類当たり最低何ビット必要か。

  1. 4ビット
  2. 5ビット
  3. 6ビット
  4. 3ビット
答えと解説を読む

正解：2．5ビット

ヒント
2の累乗のうち、21以上になる最小のものを探そう。

解説
4ビットでは2⁴＝16種類までで、21種類には足りない。5ビットなら2⁵＝32種類を表せるため、最小は5ビットである。6ビットでも表せるが、最小ではない。

解いたあとは、考え方を整理。

1．二進数は、右から桁の重みを見る

2進数の各桁は、右から1、2、4、8、16…という重みを持ちます。「10110」なら、1が立っている16、4、2を足します。0の桁の重みを足していないかも確認しましょう。

2．「何種類」と「最大いくつ」は違う

5ビットには32通りのビット列があります。符号なし整数として0から表す場合、その範囲は0から31です。最大値を問われているのか、表せる種類の数を問われているのかを、計算前に読み分けます。

3．必要なビット数は、足りるところまで増やす

21種類を区別したいとき、4ビットの16通りでは足りず、5ビットの32通りなら足ります。必要な種類数以上を表せる最小の桁数を探します。例題ではスタンプを固定長の2進符号で区別する場面を扱っています。
