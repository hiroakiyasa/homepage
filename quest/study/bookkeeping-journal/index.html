例題 1 / 3級・仕訳総合演習

売掛金を普通預金で回収

【日商簿記3級｜3級・仕訳総合演習】桜井サービスの演習ケース1：売掛金を普通預金で回収した。金額は44,000円です。最も適切な仕訳はどれですか。

  1. 仕訳を行わない
  2. 仕訳なし
  3. 借：売掛金 44,000円 ／ 貸：普通預金 44,000円
  4. 借：普通預金 44,000円 ／ 貸：売掛金 44,000円
答えと解説を読む

正解：4．借：普通預金 44,000円 ／ 貸：売掛金 44,000円

ヒント
資産・負債・収益・費用のどれが増減したかを先に判定します。

解説
取引の増減を勘定要素へ分解すると、借方は「普通預金」44,000円、貸方は「売掛金」44,000円です。

例題 2 / 3級・仕訳総合演習

銀行から借り入れて普通預金へ入金

【日商簿記3級｜3級・仕訳総合演習】若葉テックの演習ケース1：銀行から借り入れ、普通預金へ入金された。金額は86,000円です。最も適切な仕訳はどれですか。

  2. 借：借入金 86,000円 ／ 貸：普通預金 86,000円
  3. 仕訳なし
  4. 借：現金 86,000円 ／ 貸：借入金 86,000円

正解：1．借：普通預金 86,000円 ／ 貸：借入金 86,000円

ヒント
資産・負債・収益・費用のどれが増減したかを先に判定します。

解説

例題 3 / 3級・仕訳総合演習

商品を掛けで仕入れる

【日商簿記3級｜3級・仕訳総合演習】光栄物流の演習ケース1：商品を掛けで仕入れた。金額は42,000円です。最も適切な仕訳はどれですか。

  1. 仕訳を行わない
  2. 仕訳なし
  3. 借：仕入 42,000円 ／ 貸：買掛金 42,000円
  4. 借：買掛金 42,000円 ／ 貸：仕入 42,000円
答えと解説を読む

正解：3．借：仕入 42,000円 ／ 貸：買掛金 42,000円

ヒント
資産・負債・収益・費用のどれが増減したかを先に判定します。

解説
取引の増減を勘定要素へ分解すると、借方は「仕入」42,000円、貸方は「買掛金」42,000円です。

解いたあとは、考え方を整理。

1．取引で動いたものを二つに分ける

売掛金44,000円を普通預金で回収した例では、普通預金が増え、売掛金が減っています。入金があったという事実だけで勘定科目を決めず、何の代金を受け取ったのかまで読み取ります。

2．入金の理由から、相手科目を判断する

銀行から86,000円を借り入れ、普通預金へ入金された例では、普通預金と借入金が増えています。先の売掛金回収とは、普通預金が増える点が同じでも、相手科目が違います。例題の選択肢と解説で、その違いを確認してください。

3．現金が動かない取引も記録する

商品42,000円を掛けで仕入れた例では、教材の仕訳は借方が仕入、貸方が買掛金です。その場で代金を支払わなくても、取引によって発生した内容を記録します。

最後に、借方と貸方の金額が一致しているかを確認します。答えを見たあとも、各科目を選んだ理由を言葉にして振り返りましょう。

次の復習につなげる3ステップ

  1. 取引文から、受け取ったもの・支払ったもの・後で受け取るもの・後で支払うものを整理する。
  2. 動いた勘定科目と増減を考える。
  3. 借方・貸方と金額を選び、解説と照らし合わせる。
  4. アプリでは、混同した取引の問題をまちがい直しで確認する。
