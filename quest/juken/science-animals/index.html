こん虫

こん虫は「からだ・変態・分類」の3点セット。

こん虫のからだ

  • 頭・胸・腹の3つに分かれる。あし6本とはね（ふつう4枚）は胸についている
  • 触角は1対、目は複眼と単眼。腹や胸の横にある気門から空気を取り入れる
  • ハエ・カ・アブのはねは2枚（後ろのはねは退化）

こん虫でない仲間

  • クモ：あし8本、体は頭胸部と腹部の2つ
  • ダンゴムシ・エビ・カニ：甲殻類（節足動物だがこん虫ではない）
  • ムカデ：多足類。カタツムリ・ミミズ：節足動物ではない
変態のしかた
変態育ち方例
完全変態卵→幼虫→さなぎ→成虫チョウ・ガ・カブトムシ・ハチ・アリ・ハエ・カ
不完全変態卵→幼虫→成虫（さなぎがない）バッタ・トンボ・セミ・カマキリ・コオロギ

冬のすごし方の例：卵（カマキリ）、幼虫（カブトムシ）、さなぎ（アゲハ・モンシロチョウ）、成虫（ナナホシテントウ）。トンボの幼虫（ヤゴ）は水の中で育ちます。

動物の分類

セキツイ動物5グループは「表」で覚える。

体温・呼吸・生まれ方・体の表面を、グループごとに横に見ます。

セキツイ動物の比べ方
グループ体温呼吸子の生まれ方体の表面例
魚類変温えら卵生（水中に殻のない卵）うろこメダカ・フナ・サメ
両生類変温子：えらと皮膚／成体：肺と皮膚卵生（水中に殻のない卵）しめった皮膚カエル・イモリ
は虫類変温肺卵生（陸上に殻のある卵）かたいうろこトカゲ・ヘビ・カメ
鳥類恒温肺卵生（陸上に殻のある卵）羽毛ハト・ペンギン
ホニュウ類恒温肺胎生（乳で育てる）毛ヒト・クジラ・コウモリ

例外の確認

カモノハシは卵を産みますがホニュウ類です。クジラ・イルカは水中にすみますが、肺で呼吸するホニュウ類。コウモリは空を飛びますが、ホニュウ類です。

歯と目で見分ける草食・肉食

草食動物：草をすりつぶす臼歯が発達し、目は顔の横について広い範囲が見える。肉食動物：えものをしとめる犬歯が発達し、目は前を向いて、えものまでの距離がつかみやすい。

無セキツイ動物

節足動物（こん虫・甲殻類・クモなど）、軟体動物（貝・イカ・タコ）など。背骨がありません。

消化と吸収

食べ物の通り道と、消化液のはたらき。

消化器官の並びと、「どの消化液が何を分解するか」は毎年のように出ます。

消化液と消化酵素
消化液つくる場所分解するもの
だ液（アミラーゼ）だ液せんでんぷん → 麦芽糖など
胃液（ペプシンと塩酸）胃たんぱく質
すい液すい臓でんぷん・たんぱく質・脂肪のすべて
胆汁肝臓（胆のうにためる）消化酵素はふくまない。脂肪の消化を助ける

食べ物の通り道

  • 口 → 食道 → 胃 → 十二指腸 → 小腸 → 大腸 → こう門
  • 小腸：養分を吸収する中心。内側の柔毛で表面積が広い
  • 大腸：おもに水分を吸収

吸収された養分のゆくえ

  • ブドウ糖・アミノ酸は小腸の毛細血管から吸収され、血液に乗って肝臓へ
  • 脂肪は分解されて吸収されたあと、柔毛の中でふたたび脂肪になり、リンパ管へ
  • 肝臓は、養分をたくわえる・胆汁を作る・有害なものを無害にするはたらきがある
血液と呼吸

心臓の4つの部屋と、血液の流れ。

「動脈血・静脈血」と「動脈・静脈」をとりちがえるのが一番のつまずきです。

血液の流れ（体循環と肺循環）
経路流れる順血液
体循環左心室 → 大動脈 → 全身 → 大静脈 → 右心房大動脈は動脈血（酸素が多い）、大静脈は静脈血
肺循環右心室 → 肺動脈 → 肺 → 肺静脈 → 左心房肺動脈は静脈血、肺静脈は動脈血
血液の成分
成分はたらき
赤血球酸素を運ぶ（ヘモグロビン）
白血球細菌などをとらえて体を守る
血小板出血したとき血液を固める
血しょう養分・二酸化炭素・不要なものをとかして運ぶ

呼吸のしくみ

  • 鼻・口 → 気管 → 気管支 → 肺胞。肺胞のまわりの毛細血管で、酸素と二酸化炭素を交換する
  • 息を吸うとき：横隔膜が下がり、ろっ骨が上がる。はくときはその逆
  • 吸う空気より、はく息のほうが、酸素は少なく二酸化炭素は多い

いらないものの排出

  • 腎臓が血液から尿素などをこし出して、尿を作る。尿はぼうこうにたまる
  • 二酸化炭素は肺から、水と塩分の一部は汗としても出る
感覚・生まれ方

目・耳・運動と、ヒトとメダカのたんじょう。

目と耳

  • 目：光は角膜・水晶体を通って網膜に像を結ぶ。明るいところではひとみ（虹彩で調節）が小さくなる
  • 耳：音は鼓膜・耳小骨・うずまき管へ。体の回転を感じるのは半規管

筋肉と骨

  • うでを曲げるとき、うでの内側（上腕二頭筋）が縮み、外側がゆるむ
  • 筋肉は腱（けん）で骨につき、関節をはさんで動かす

ヒトのたんじょう

  • 卵（母親）と精子（父親）が受精して受精卵になり、子宮で育つ
  • 胎児は、たいばんとへその緒で母親から酸素と養分を受け取り、羊水が衝撃から守る
  • 受精からおよそ38週（約266日）で生まれる

メダカのたんじょう

  • おすはせびれに切れ込みがあり、しりびれは平行四辺形に近い。めすはせびれに切れ込みがなく、しりびれの後ろ側が短い
  • 卵は直径約1mm。水温25℃ほどで、10日前後でふ化する
  • ふ化直後は、はらのふくろの養分で育つ

数値は教材によって表記が異なる場合があります（ヒトの受精卵の大きさ、メダカのふ化日数など）。使っている教材の数字に合わせてください。

確認

自分でこたえて、答えを開いて確かめる。

覚えたつもりを、6問で点検します。

こん虫の体は3つに分かれます。どこに何があるでしょう。

頭（目・触角・口）、胸（あし6本・はね）、腹（気門から呼吸）。あしとはねは胸についています。

完全変態と不完全変態のちがいと、それぞれの例を答えなさい。

完全変態は卵→幼虫→さなぎ→成虫（チョウ・カブトムシ・ハチ・ハエ）。不完全変態はさなぎの時期がなく、卵→幼虫→成虫（バッタ・トンボ・セミ・カマキリ）。

だ液にふくまれる消化酵素の名前と、はたらきを答えなさい。

アミラーゼ。でんぷんを麦芽糖などに分解します。ヨウ素液でためすと、でんぷんが分解されると青紫色にならなくなります。

酸素を多くふくむ血液が流れる血管を、すべて答えなさい。

肺静脈と大動脈です（動脈血）。肺動脈と大静脈は二酸化炭素の多い静脈血が流れます。

胆汁（たんじゅう）はどこで作られ、どんなはたらきをしますか。

肝臓で作られ、胆のうにたくわえられます。消化酵素はふくまず、脂肪の消化を助けます。

ヒトが息を吸うとき、横隔膜とろっ骨はどう動きますか。

横隔膜が下がり、ろっ骨が上がります。胸の中の空間が広がって、肺に空気が入ります。

よくある質問

動物・人体のまとめのよくある質問。

中学受験の理科で、動物・人体は入試直前に何から確認すればよいですか？

①こん虫の体のつくりと変態、②セキツイ動物5グループの表、③消化液とそのはたらき、④心臓と血液の流れ、⑤呼吸、の順がおすすめです。どれも表にして覚えると、まとめて思い出せます。

動脈血と静脈血のちがいは何ですか？

酸素を多くふくむ血液が動脈血、二酸化炭素を多くふくむ血液が静脈血です。血管の名前（動脈・静脈）とは別の分け方で、肺動脈には静脈血、肺静脈には動脈血が流れます。

人体の分野が苦手です。どう復習すればよいですか？

図や言葉をそのまま覚えるより、「通り道を順番に口で言う」「消化液・血管を表に書き出す」と定着しやすくなります。一問一答でまちがえたものだけを、日をおいて解き直す方法も有効です。
